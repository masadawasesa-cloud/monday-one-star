A one-line review of Monday, rated one star: at the security desk I was told I looked much younger in my ID photo — and the photo was taken on Friday. The program writes the review, word for word, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `/output` (or to `$MAKEFUN_OUTPUT_DIR` when that is set).
